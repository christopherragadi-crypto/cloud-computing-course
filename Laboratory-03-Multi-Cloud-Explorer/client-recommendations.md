# Client Recommendations

## Client A – Startup Company

**Recommended Cloud Platform: AWS**

AWS would be a good choice because it offers many cloud services that can fit a limited budget. The startup can begin with smaller resources and increase them as the mobile application grows. AWS also provides flexible and scalable services that can support the company in the future.

**Services they could use:**

- Amazon EC2 – Application computing
- Amazon S3 – File and data storage
- Amazon RDS – Managed database
- Amazon CloudFront – Faster content delivery

---

## Client B – University

**Recommended Cloud Platform: Microsoft Azure**

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with Microsoft technologies, making the migration easier for the university. It can also help manage users, applications, and data in the cloud.

**Services they could use:**

- Azure Virtual Machines – Running Windows Server workloads
- Microsoft Entra ID – Identity and access management
- Azure Storage – Cloud storage
- Azure SQL Database – Managed database service

---

## Client C – AI Research Company

**Recommended Cloud Platform: Google Cloud Platform (GCP)**

Google Cloud Platform is a strong choice because it provides powerful tools for Artificial Intelligence and Machine Learning. It offers high-performance computing resources that can handle complex AI workloads and large datasets. GCP also provides services that help researchers develop, train, and deploy AI models.

**Services they could use:**

- Google Compute Engine – High-performance computing
- Google Vertex AI – Building and training AI/ML models
- Google Cloud Storage – Storing large datasets
- Google Kubernetes Engine (GKE) – Running containerized applications

---

## Client D – Global E-Commerce Company

**Recommended Cloud Platform: AWS**

AWS is a suitable choice because it provides highly available and scalable infrastructure for global businesses. The company can automatically increase or decrease resources based on customer traffic. AWS also provides global services that can help the company deliver a fast and reliable shopping experience.

**Services they could use:**

- Amazon EC2 – Scalable application servers
- Amazon EC2 Auto Scaling – Automatic scaling
- Amazon RDS – Managed relational database
- Amazon CloudFront – Global content delivery
- Elastic Load Balancing – Distributes traffic across servers


# Multi-Cloud Decision Matrix

| **Business Requirement** | **Recommended Platform** | **Justification** |
|---|---|---|
| Startup Company | AWS | Affordable, flexible, and easy to scale. |
| Enterprise Organization | AWS | Reliable, secure, and supports large businesses. |
| Microsoft Environment | Azure | Works well with Microsoft products. |
| AI / Machine Learning | GCP | Strong AI and Machine Learning tools. |
| Kubernetes Deployment | GCP | GKE makes Kubernetes easier to manage. |
| Global Web Application | AWS | Global infrastructure with strong scalability. |
