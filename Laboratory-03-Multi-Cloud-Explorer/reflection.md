# Mission Reflection

### 1. Which cloud platform impressed you the most?
**Amazon Web Services (AWS)** stood out to me the most, mainly because of how mature and complete its platform feels. Having been around the longest, AWS has a tool for almost every niche problem you can think of. Plus, whenever you run into a bug or need to figure something out, the community support and online troubleshooting resources are usually miles ahead of the rest.

### 2. What similarities exist among AWS, Azure, and GCP?
At their core, all three providers build on the exact same underlying concepts. They each structure their physical servers into global Regions and isolated Availability Zones to keep things reliable. They also offer the same foundational building blocks virtual machines, object storage, isolated networks, and IAM security controls and charge you using a flexible pay as you go model.

### 3. How do business requirements influence cloud platform selection?
A company's choice usually boils down to its current tech stack, internal budget, and specific software goals. For example, a business running heavily on legacy Windows software and Active Directory will almost always lean toward Microsoft Azure for cheaper licensing and easy integration. On the flip side, a modern startup focused on machine learning or big data will likely pick GCP for its Vertex AI and container performance.

### 4. What did you learn from acting as a Cloud Solutions Consultant?
Stepping into the consultant mindset made me realize that technical decisions aren't just about picking the fastest or newest tech it's about balancing practical trade offs. You have to carefully weigh things like cost, existing developer skills, maintenance overhead, and vendor lock-in to recommend an architecture that actually fits a team's real-world needs.

### 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?
This task gave my portfolio a huge boost by showing I can turn hands on terminal work into clear, professional documentation. Instead of just listing basic Linux commands, I showed how to inspect actual server hardware and map those specs directly to AWS, Azure, and GCP compute tiers. It gives potential employers a clear look at my technical understanding and my ability to communicate cloud concepts effectively.
